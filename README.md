# Passive Tree Prototype

Path of Building 스타일 패시브 트리 UI를 React Flow로 만든 프로토타입입니다.

## Features

- 노드 종류: Initial, Connect, Small, Notable, Mastery
- 노드 추가 / 삭제 / 복사·붙여넣기
- Mastery 오르빗(최대 3단) + 빈 슬롯 간격
- Initial → Connect 파워 전파, Notable 트레이닝 밴드(3/5/7)
- 패시브 클래스(아이콘·색상)

## Run

```bash
npm install
npm run dev
```

## Stack

- Vite + React + TypeScript
- `@xyflow/react` (React Flow)
