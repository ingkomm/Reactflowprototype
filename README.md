# Passive Tree Prototype

Path of Building 스타일 패시브 트리 UI를 React Flow로 만든 간단한 프로토타입입니다.

## Features

- 노드 추가 / 삭제
- 노드 종류: Small Passive, Notable Passive, Mastery
- 원형 노드 + 중심점(center) 연결
- 노드별 트레이닝 횟수 다중 등록

## Run

```bash
npm install
npm run dev
```

## Stack

- Vite + React + TypeScript
- `@xyflow/react` (React Flow)
